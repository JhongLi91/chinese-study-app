# Chinese Study App

A simple web application to learn and memorize Chinese characters using flashcards and interactive games.

> **Note:** This is a pure client-side frontend application—no backend server or dedicated database is required.

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or newer)
- [Git](https://git-scm.com/)

## Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/JhongLi91/chinese-study-app.git
cd chinese-study-app
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the app
```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
